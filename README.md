# CUI — The C User Interface Framework ⚡️

CUI is a **lightweight, high-performance UI library written entirely in C** — from scratch.
Designed for developers who want **full control over UI rendering** without bloated dependencies.

---

## 🚀 Features

- **Minimal & Fast** — Written purely in C with zero external dependencies (well unless you consider stb_image as a dependency).
- **Flexible Components** — button, canvas, edit, panel.
- **Custom Rendering** — Fully control how your UI looks and behaves.
- **Cross-Platform Ready** — Built with Windows in mind (Linux/Mac support in progress).
- **Low-Level Access** — Access to every pixel and event, perfect for games, tools, or custom editors.

---

## ⚙️ Getting Started

Clone the repo:
```bash
git clone https://github.com/MrGreber/cui.git
cd cui
```

Build with CMake:
```bash
mkdir build
cd build
cmake ..
cmake --build .
```
